## 1. 先從教材 `iterative3.py` 學到的事：迭代法三大要素

教材只用 9 行就示範了迭代法的全部重點：**同一個問題，寫出不同的迭代式，
收斂速度天差地遠**。

```python
f1 = lambda x: 3 / x                 # 迭代式 1
f2 = lambda x: x - 1 / 4 * (x * x - 3)   # 迭代式 2
f3 = lambda x: 1 / 2 * (x + 3 / x)       # 迭代式 3

x1 = x2 = x3 = 1
for i in range(20):
    x1, x2, x3 = f1(x1), f2(x2), f3(x3)
    print('x1:', x1, 'x2', x2, 'x3', x3)
```

它解的問題是求 **√3**（也就是解方程式 `x² = 3`）。三種迭代式的收斂行為（實測）：

```text
x1: 3.0  x2 1.5                    x3 2.0           ; 第 0 步
x1: 1.0  x2 1.6875                 x3 1.75
x1: 3.0  x2 1.7255859375           x3 1.73214285714...
x1: 1.0  x2 1.7311742305755615     x3 1.73205081001...
x1: 3.0  x2 1.7319331764233397     x3 1.7320508075688772   ; x3 已收斂!
...
x1: 1.0  x2 1.7320508075688767     x3 1.7320508075688772   ; x2 到第 19 步才收斂
x1: 3.0  x2 1.7320508075688772     x3 1.7320508075688772   ; x1 永遠在 1 / 3 之間跳
```

用迭代法的收斂理論解釋（`迭代法收斂定理：|g'(x*)| < 1 才會收斂`）：

| 迭代式 | 科學名稱 | `g'(√3)` | 收斂 | 到誤差 1e-12 的步數 |
|--------|----------|----------|------|---------------------|
| `x1 = 3/x` | 倒數迭代 | **-1** | **不收斂**：在 1↔3 之間做 2-循環 | ∞ |
| `x2 = x - (x²-3)/4` | 阻尼牛頓（把導數 `2x` 換成常數 `4`） | 1-√3/2 ≈ **0.134** | 線性收斂 | 15 步 |
| `x3 = (x+3/x)/2` | 巴比倫法 = **牛頓法**（`x-(x²-3)/(2x)` 化簡後就是它） | **0** | 二次收斂 | 5 步 |

三點結論，就是理解 `iter_framework.py` 的鑰匙：

1. **迭代法需要「轉移函數」**：`x_{n+1} = g(x_n)`。`x1` 選錯就永遠不收斂；
2. **迭代法需要「初始值」**，例如三個迭代式都從 `x=1` 出發；
3. **迭代法需要「停止/收斂判定」**：教材固定跑 20 步，但更聰明的方法是「誤差夠小就停」。

`iter_framework.py` 正是把這「三大要素」抽象成一個通用的函式，再用它一口氣
重寫 9 個經典演算法 —— 這叫作 **框架化（framework）**。

## 2. 框架總覽：用一個 `generic_iterator` 打天下

框架的核心只有一個函式：

```python
def generic_iterator(transition_func, is_converged, initial_state, max_iter=1000):
    state = initial_state
    for iteration in range(max_iter):
        next_state = transition_func(state)          # ① 推進：state -> next_state

        if is_converged(state, next_state, iteration):  # ② 判斷要不要停
            return next_state, iteration + 1

        state = next_state                            # ③ 更新：把狀態交給下一輪

    print("  [警告] 達到最大迭代次數仍未完全收斂")
    return state, max_iter
```

### 逐行解說

| 行 | 說明 |
|----|------|
| `transition_func(state)` | 對應教材的 `g(x)`。傳一個 `state`，回傳下一個 `state`。**「狀態」不做任何型別假設**：可以是浮點數、向量、矩陣、tuple……所有演算法都吃同一張合約。 |
| `is_converged(state, next_state, iteration)` | 收斂判定。拿到「舊狀態、新狀態、目前步數」三個資訊，回傳是否該停。 |
| `initial_state` | 初始值/初始猜測。 |
| `max_iter=1000` | 保險絲：避免收斂不了時無窮迴圈，到頂就印警告。 |
| `return next_state, iteration + 1` | 回傳兩個值：**最終狀態**與**實際用了幾步**，方便比較演算法。 |

### 資料流

```text
    initial_state
         │
         ▼
    ┌──────────────┐    transition_func     ┌──────────────┐
    │  state(T)    │ ─────────────────────► │ next_state   │
    └──────────────┘                        └──────┬───────┘
         ▲                                        │ is_converged
         │            差太遠, 繼續:                   │ 已收斂:
         └──────────── state <- next_state ◄────────┼── 回傳 (next_state, 步數)
                                                   │ (誤差夠小, 停止)
```

### 為什麼這張介面能裝下 9 個演算法？

關鍵在於三個設計決定：

1. **`state` 不放任何型別限制** → 純量解方程（牛頓）、向量解線性系統（GS）、
   矩陣算特徵值（QR）、tuple 推進微分方程（RK4）全部能用同一個函式。
2. **`transition_func` 是唯一需要「客製化」的部分** → 每個演算法的數學都被
   封裝成一個小閉包，放進來就能跑。
3. **`is_converged` 拿到的是「舊/新狀態」成對資料** → 可以實作三種不同的
   停止策略（見下表），想要哪種就換哪個 lambda。

### 收斂判定的三種典型策略

| 策略 | 寫法 | 適合的情境 |
|------|------|-----------|
| 前後步誤差夠小 | `abs(new - old) < tol` | 根 / 固定點 / 特徵值：收斂時步長會趨近 0 |
| 向量的長度變化夠小 | `np.linalg.norm(new - old) < tol` | 高維狀態（向量、機率分佈） |
| 達到目標條件 | `new[0] >= t_end - 1e-9` | ODE 積分：積分時間到達終點就該停 |

## 3. 九個經典演算法逐一解說

以下每個演算法的「trans 對應式」都直接來自程式碼，並附上實際執行的輸出。

### 3.1 二維不動點迭代法（Fixed-Point Iteration）

解聯立方程式 `X = M·X + b`，把它直接寫成不動點形式：

```text
x1' = 0.5 x1 - 0.2 x2 + 0.3
x2' = 0.2 x1 + 0.5 x2 + 0.4
```

程式碼：

```python
transition = lambda X: np.array([0.5*X[0]-0.2*X[1]+0.3, 0.2*X[0]+0.5*X[1]+0.4])
converged  = lambda old, new, i: np.linalg.norm(new - old) < 1e-6
```

輸出：

```text
結果: [0.24138  0.896552] (耗時 23 次迭代)
```

分析：迭代矩陣的兩個特徵值是 `0.5 ± 0.2i`，譜半徑 **ρ = 0.5385**（線性收斂），
所以每步誤差大約縮小一半，要 23 步才到 1e-6。收斂很穩，但不算快。

### 3.2 牛頓法求根（`x² - 4 = 0`）

牛頓法把「解 f(x)=0」轉成迭代：`x_{n+1} = x_n - f(x_n)/f'(x_n)`。

```python
f  = lambda x: x**2 - 4.0
df = lambda x: 2.0 * x
transition = lambda x: x - f(x) / df(x)
converged  = lambda old, new, i: abs(new - old) < 1e-6
```

輸出：

```text
結果: 根 x = 2.000000 (耗時 5 次迭代)
```

分析：**二次收斂**。實測誤差序列 `5e-1 → 5e-2 → 6.1e-4 → 9.3e-8 → 2.2e-15`，
每一格的誤差是上一格的平方量級（`e_{n+1} ≈ 0.25 e_n²`）：正確位數每次翻倍，
5 步就把雙精度榨乾。這是 9 個演算法裡收斂最快的模式。

### 3.3 高斯-賽得爾法（Gauss-Seidel，解線性系統 Ax = b）

解三對角系統：

```text
4x1 - x2      = 7
-x1 + 4x2 - x3 = 2
     -x2 + 4x3 = 13
```

迭代式：`x_i = (b_i - Σ_{j≠i} A_ij · x_j) / A_ii`（第 i 條方程式解出第 i 個未知數，
新值馬上被後面的變數使用）。

```python
def transition(x):
    x_new = x.copy()
    for i in range(n):
        s = sum(A[i, j] * x_new[j] for j in range(n) if j != i)
        x_new[i] = (b[i] - s) / A[i, i]
    return x_new
converged = lambda old, new, i: np.max(np.abs(new - old)) < 1e-6
```

輸出：

```text
結果: x = [2.25 2.   3.75] (耗時 9 次迭代)
```

分析：正確解 `x* = [2.25, 2, 3.75]`。這是線性收斂，收斂速度由迭代矩陣
`B_GS = (D+L)⁻¹(-U)` 的譜半徑決定，此例 **ρ(B_GS) = 0.125**；若改用
未更新的雅可比（Jacobi）法，ρ = 0.354，會慢將近 3 倍 —— 高斯-賽得爾的
「一路用新值」就是它的加速關鍵。

### 3.4 冪次迭代法（Power Iteration，找最大特徵值/向量）

反覆 `v ← A·v` 再歸一化，向量會收斂到最大特徵值對應的特徵向量：

```python
transition = lambda v: np.dot(A, v) / np.linalg.norm(np.dot(A, v))
converged  = lambda old, new, i: np.allclose(old, new, atol=1e-6)
```

輸出：

```text
結果: 最大特徵值 = 4.721570 (耗時 17 次迭代)
```

分析：矩陣三個特徵值為 `4.7216, 2.3983, 1.8801`，比值 **λ₁/λ₂ = 1.969**。
冪次迭代的收斂速度由這個比值決定：每步把非主導分量的誤差乘上 1/1.969，
即每步多對約 0.6 位小數，屬**線性收斂**。特徵值間隔越小，就要越多次迭代。

### 3.5 QR 演算法（一次拿到所有特徵值）

反覆做 `QR = λA`（QR 分解）再 `A ← R·Q`，對角線會收斂到全部特徵值：

```python
transition = lambda Ak: np.dot(*reversed(np.linalg.qr(Ak)))
converged  = lambda old, new, i: np.sum(np.abs(new - np.diag(np.diagonal(new)))) < 1e-6
```

輸出：

```text
結果: 所有特徵值 = [5.732051 2.267949 1.      ] (耗時 19 次迭代)
```

分析：實測「非對角線元素的絕對值和」每步約縮小 0.42 倍（被次主導對角元素的
比值控制），19 步把非對角元素壓到 1e-6 以下，對角線就幾乎是特徵值
`[5.732, 2.268, 1.0]`。QR 被譽為「電腦算特徵值最標準的做法」。

### 3.6 龍格-庫塔法（RK4，數值積分 ODE）

解一階微分方程 `dy/dt = y - t + 1, y(0) = 1`。狀態是 **tuple `(t, y)`**，
每步努力逼近泰勒展開到 4 階：

```python
def transition(state):
    t, y = state
    k1 = f(t, y)
    k2 = f(t + 0.5*h, y + 0.5*h*k1)
    k3 = f(t + 0.5*h, y + 0.5*h*k2)
    k4 = f(t + h,    y + h*k3)
    return (t + h, y + (h/6.0) * (k1 + 2*k2 + 2*k3 + k4))
converged = lambda old, new, i: new[0] >= t_end - 1e-9   # 時間到就停
```

輸出：

```text
結果: 於 t = 2.0 時, y = 9.388889 (耗時 10 步)
```

分析：解析解 `y = eᵗ + t`，正確值 `y(2) = e² + 2 = 9.3890560989…`。
實測誤差隨著步距 h 縮一半而降約 14 倍（≈ 2⁴），正是 **O(h⁴)** 的證據：
步距對半 → 誤差除以約 16。這裡的「迭代」不是「逼近某個固定解」，而是
**一步步把時間推前**，停止條件也從「誤差夠小」換成「時間到」——完全靠
`is_converged` 拿到三參數的彈性。

### 3.7 PageRank（Google 排序 = 冪次迭代的實際應用）

把網頁想成「隨機衝浪者」在轉移矩陣 `M` 上漫遊，問長期下來停留在各頁的
機率分佈。用 `d·M + (1-d)/n` 的 Google 矩陣 `G` 做冪次迭代：

```python
transition = lambda r: np.dot(G, r)                  # G 就是轉移矩陣
converged  = lambda old, new, i: np.linalg.norm(new - old) < 1e-6
```

輸出：

```text
結果: 網頁權重分佈 = [0.3246 0.2251 0.2251 0.2251] (耗時 15 次迭代)
```

分析：`G` 的最大特徵值是 1（機率矩陣的性質），次大的是 **0.425**，因此收斂
速率因子就是 0.425，屬線性收斂。第 1 頁權重最高（0.3246）是因為它被其他頁
大量連入。本範例把「馬可夫鏈的穩態」跟「最大特徵向量」兩個概念接在一起，也
證明**冪次迭代只要換掉 transition，就變成一套全新的演算法**。

### 3.8 K-Means 聚類（Hard EM）

先隨機產生兩團 2-D 資料（各 15 點），演算法在「E 步：把每點指派給最近的
中心」與「M 步：把中心移到該類的平均」之間反覆，直到中心不再動：

```python
def transition(centroids):
    distances = np.linalg.norm(X[:, np.newaxis] - centroids, axis=2)  # E 步
    labels    = np.argmin(distances, axis=1)
    return np.array([X[labels == j].mean(axis=0) for j in range(k)])   # M 步
converged = lambda old, new, i: np.max(np.abs(new - old)) < 1e-6
```

輸出：

```text
結果: 最終分群中心 =
[[-2.1143 -2.128 ]
 [ 1.826   1.7977]] (耗時 4 次迭代)
```

分析：兩團中心分別落在 `(±1.8~2.1, ±1.8~2.1)`，因為初始中心是直接抓前兩顆
資料點，演算法 4 步就收斂。特別的是：**K-Means 的 transition 同時做了決策
（指派標籤）與參數更新（移動中心）**，證明框架不只裝得下「純數值迭代」，
也裝得下「離散決策 + 連續更新」的混合過程。

### 3.9 EM 演算法（兩銅板問題）

已知兩枚硬幣 A、B 的資料是一整批「正面/反面統計」，但**不知道每一輪用的
是哪一枚**（潛在變數）。EM 靠「E 步算期望權重、M 步重新估計機率」收斂：

```python
# E 步: 用目前的 theta 估計每一輪是 A 或 B 的機率 p_A, p_B，加總成期望統計量
# M 步: theta_A = 期望正面數 / 總投擲數, theta_B 同理
converged = lambda old, new, i: abs(new[0]-old[0]) < 1e-6 and abs(new[1]-old[1]) < 1e-6
```

輸出：

```text
結果: 估計硬幣機率 Theta_A = 0.7968, Theta_B = 0.5196 (耗時 16 次迭代)
```

分析：標準答案在文獻中約為 `θA ≈ 0.80, θB ≈ 0.52`，程式估出
`(0.7968, 0.5196)`。EM 是**線性收斂**（資料庫裡常說「EM 越靠近解越慢」），
步數從 16（1e-6）到 44（1e-15）可見尾段明顯變緩，這是因為潛在變數讓
M 步的更新量與梯度的比值會隨接近解而縮小所導致。

## 4. 收斂速率總表（本機實測）

| 編號 | 演算法 | state 型別 | 收斂性質 | 實測步數（到 1e-6） | 收斂速率關鍵 |
|------|--------|-----------|---------|--------------------|--------------|
| 1 | 不動點迭代 | 向量 (2,) | 線性 | 23 | ρ = 0.5385 |
| 2 | 牛頓法 | 純量 | **二次** | **5** | e_{n+1} ≈ 0.25 e_n² |
| 3 | 高斯-賽得爾 | 向量 (3,) | 線性 | 9 | ρ(B_GS) = 0.125 |
| 4 | 冪次迭代 | 向量 (3,) | 線性 | 17 | λ₁/λ₂ = 1.969 |
| 5 | QR 演算法 | 矩陣 (3,3) | 線性 | 19 | 非對角元 ~0.42^n |
| 6 | RK4 | tuple (t,y) | O(h⁴) 積分 | 10 步（h=0.2） | 誤差 ∝ h⁴ |
| 7 | PageRank | 向量 (4,) | 線性 | 15 | λ₂/λ₁ = 0.425 |
| 8 | K-Means | 矩陣 centroids | 有限步 | 4 | 資料點夠乾淨 |
| 9 | EM | tuple (θA,θB) | 線性 | 16 | 越近解越慢 |

通則：**只有「二次收斂」的牛頓法要 5 步，其餘線性收斂都要十幾二十步。**
這正是自訂問題 `pi_iterative.py` 想要強調的量級差距。

```text
結果: 估計硬幣機率 Theta_A = 0.7968, Theta_B = 0.5196 (耗時 16 次迭代)
```

## 6. 框架的優點與限制

**優點**

1. **一份合約、九種演算法**：框架核心只有「推進 / 判定 / 初始值」三件事，
   換函數就換演算法（例如 3.4 的冪次迭代跟 3.7 的 PageRank 結構一模一樣）。
2. **便於比較與研究**：統一回傳 `(最終狀態, 步數)`，步數可直接拿來比較
   不同演算法、不同收斂準則的成本。
3. **狀態無型別假設**：純量、向量、矩陣、tuple 通吃，因此能同時涵蓋
   解方程、解線性系統、找特徵值、積分 ODE、機率模型…… 每個範例的
   `transition` 都小於 10 行。

**限制**

1. **`max_iter` 只防無窮迴圈，不改收斂性質**：選錯迭代式（如教材 `f1`）時
   它只能印警告，不會幫你收斂。
2. **收斂判斷仍要使用者自己寫**：不同問題的「誤差度量」不同（步長、範數、
   非對角元總和、時間是否到點），框架不越俎代庖。
3. **通用性的代價是「不知道數學」**：不像特化的數值方法套件（如 SciPy），
   它不會自動用線性搜尋、步長控制等技巧，適合教學 / 原型，不適合超大規模。

## 7. 自訂問題：用迭代法求 π（`pi_iterative.py`）

呼應教材的精神：**同一個問題，寫出多種迭代式，比較收斂速度**。
π 沒有封閉式，只能靠極限逼近，正好是理想的迭代練習。本檔用了 6 種迭代法：

| 方法 | 迭代式精華 | 收斂階 |
|------|-----------|--------|
| 1. Viete 連乘 | `a←√(2+a)`，`π≈2·Π(2/aᵢ)` | 線性，每步 +1 位小數 |
| 2. Wallis 乘積 | `π/2 = Π (2n)²/((2n-1)(2n+1))` | 線性，誤差 ~ π/4N，**慢到不能用** |
| 3. Machin+Gregory | `π/4 = 4·atan(1/5) - atan(1/239)` | 線性，每步 +1.4 位小數 |
| 4. 牛頓法 | 解 `cos(x/2)=0`，`x ← x + 2cos(x/2)/sin(x/2)` | **二次收斂，3 步到位** |
| 5. Aitken Δ² 加速 | 對線性序列外插 `s* = sₙ - (Δsₙ)²/(Δ²sₙ)` | 把 Viete 加速 ~10 步以上 |
| 6. 蒙地卡羅 | 隨機撒點 `4·(圓內點數)/(總點數)` | O(1/√N)，**最差對照組** |

### 收斂速度總對照表（實測）

```text
  目標誤差             Viete    Wallis   Machin      牛頓法   Aitken          蒙地卡羅
  -------------------------------------------------------------------------
  小數點後  3 位         5       785        2        1        1    400,000 顆點
  小數點後  6 位        10       做不到        4        2        3   做不到 (>400萬)
  小數點後 10 位        16       做不到        7        2        6   做不到 (>400萬)
  小數點後 13 位        21       做不到        9        3        9   做不到 (>400萬)
```

牛頓法的收斂過程（二次收斂，正確位數每步平方）：

```text
第 1 次  x=3.141829688605305  誤差=2.37e-04     <- 對 3 位
第 2 次  x=3.141592653588683  誤差=1.11e-12     <- 對 12 位
第 3 次  x=3.141592653589793  誤差=0.00e+00     <- 撞上雙精度極限
```

Aitken Δ² 加速 Viete 的效果（把線性收斂變成超線性）：

```text
n= 0  原誤差=3.13e-01  Aitken 誤差=6.39e-04   改善 490 倍
n= 4  原誤差=1.26e-03  Aitken 誤差=9.50e-09   改善 132,775 倍
n= 8  原誤差=4.93e-06  Aitken 誤差=1.45e-13   改善 33,937,534 倍
=> Viete 原本要 21 步才對到 1e-13，加速後 8 步就到了。
```

最後一節直接**把牛頓法的 transition 丟進 `generic_iterator`**：

```python
transition = lambda x: x - math.cos(x/2.0) / (-0.5 * math.sin(x/2.0))
converged  = lambda old, new, i: abs(new - old) < 1e-14
result, iters = generic_iterator(transition, converged, initial_state=3.0)
```

得到 `π = 3.141592653589793`（4 次迭代），與框架第 3.2 節的「牛頓法求根」
用的是**同一個函式** —— 這就實作證明了第 2 節的主張：
**換一個 transition 就換一個演算法**，框架不需要任何改動。

## 8. 結論

- 讀懂教材 `iterative3.py`，提煉出**迭代法三大要素**：初始值、轉移函數 `g`、
  收斂判定。同一個根，`|g'(x*)| < 1` 決定收不收斂；`|g'(x*)|` 越接近 0
  收斂越快；`g'(x*) = 0` 就升級成二次收斂（牛頓法）。
- `iter_framework.py` 把這三件事抽象成一個可重用的 `generic_iterator`，
  並用同一個函式包裝了 9 種涵蓋「解方程、線性系統、特徵值、ODE、機率模型、
  聚類」的經典演算法。
- 自訂問題「求 π」用 6 種迭代法血淋淋比較了收斂階的落差：
  線性收斂要十幾二十步、Wallis 慢到不可用、二次收斂的牛頓法 3 步到位、
  隨機的蒙地卡羅更是砸資源也追不上。
- 結論一句話：**迭代法的快慢不是「努力」決定的，是「迭代式的收斂階」決定的。**
