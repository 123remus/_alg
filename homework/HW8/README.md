# HW8 - 旅行推銷員問題（TSP）解法比較

本資料夾包含使用五種不同方法解決旅行推銷員問題（Traveling Salesperson Problem, TSP）的實作。

## 實作方法

### 1. 改良法 (Improvement Method) - `改良法.py`
使用 2-opt 演算法進行局部搜尋改良。從初始路徑開始，透過交換路徑中的兩條邊來消除交叉，逐步改良解答直到無法再改善為止。

### 2. 爬山演算法 (Hill Climbing) - `爬山演算法.py`
從隨機初始解開始，每次產生鄰近解（交換兩個城市），若鄰近解較佳則接受，否則捨棄。容易陷入局部最優解。

### 3. 模擬退火法 (Simulated Annealing) - `模擬退火法.py`
結合爬山演算法概念，允許以一定機率接受較差的解答。初期溫度較高時接受較差解的機率較大，隨著溫度降低逐漸傾向接受較佳解，有助於跳脫局部最優。

### 4. 梯度下降法 (Gradient Descent) - `梯度下降法.py`
在鄰域中採樣多個鄰近解，選擇最陡下降方向（最佳改善）的解進行移動。類似爬山演算法但更傾向選擇最佳鄰近解進行更新。

### 5. 貪婪演算法 (Greedy Algorithm) - `貪婪演算法.py`
使用最近鄰居法（Nearest Neighbor），從起始城市出發，每次選擇距離當前城市最近的未訪問城市，快速建構一個可行解。雖然執行速度快，但通常不是全局最優解。

## 使用方式

```bash
python 改良法.py
python 爬山演算法.py
python 模擬退火法.py
python 梯度下降法.py
python 貪婪演算法.py
```

## 測試設定

- 城市數量：10 個
- 城市座標：隨機生成於 (0,100) x (0,100) 區間
- 隨機種子：123（確保結果可重現）
