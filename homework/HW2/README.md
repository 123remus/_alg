# HW2 : 求解遞迴方程式並找出演算法複雜度

求解下列四個遞迴方程式的**精確封閉解**，並標出對應演算法的 **Big O** 複雜度：

```
  1.  T(n) = T(n-1) + 8,     T(1) = 1
  2.  T(n) = 2T(n-1) + 9,    T(1) = 1
  3.  T(n) = 2T(n/2) + 1,    T(1) = 1
  4.  T(n) = T(n/2) + 1,     T(1) = 1
```

## 執行方式

```bash
python3 recurrence.py
```

程式會同時用「照遞迴式迭代」與「封閉公式」兩種方式算出數字並互相驗證，
全部一致才給出正確答案。

---

## 1. T(n) = T(n-1) + 8，T(1) = 1

**展開**（每次 n 減少 1，各層加 8，共 n-1 層）：

```
T(n) = T(n-1) + 8
     = T(n-2) + 8 + 8
     = ...
     = T(1) + 8·(n-1)
     = 1 + 8n - 8
```

**精確解**：`T(n) = 8n - 7`
**Big O**：`O(n)`（線性，n 翻倍時間約翻倍）

驗證：`T(1)=1, T(2)=9, T(3)=17, T(4)=25, ...`

---

## 2. T(n) = 2T(n-1) + 9，T(1) = 1

**展開**（每層遞迴呼叫加倍，公比 2 的等比級數）：

```
T(n) = 2T(n-1) + 9
     = 2[2T(n-2)+9] + 9 = 4T(n-2) + 18 + 9
     = 2^k · T(n-k) + 9·(2^k - 1)

取 k = n-1（做到 T(1)）：
T(n) = 2^(n-1) · 1 + 9·(2^(n-1) - 1)
     = 2^(n-1) + 9·2^(n-1) - 9
     = 10·2^(n-1) - 9
```

**精確解**：`T(n) = 10·2^(n-1) - 9 = 5·2^n - 9`
**Big O**：`O(2^n)`（指數，n 每加 1 時間就翻倍）

驗證：`T(1)=1, T(2)=11, T(3)=31, T(4)=71, T(5)=151, ...`

---

## 3. T(n) = 2T(n/2) + 1，T(1) = 1（令 n = 2^k）

**展開**（每下一層問題變一半，但呼叫次數加倍）：

```
T(2^k) = 2·T(2^(k-1)) + 1
       = 4·T(2^(k-2)) + 2 + 1
       = 2^j · T(2^(k-j)) + (2^j - 1)

取 j = k（做到 T(1)）：
T(n) = 2^k · 1 + (2^k - 1) = 2^(k+1) - 1
```

**精確解**：`T(n) = 2n - 1`（n = 2^k，即 n 為 2 的次方時）
**Big O**：`O(n)`（主定理 case 1：a=2, b=2, f(n)=1 = O(n^1⁻ᵉ)）

驗證：`T(1)=1, T(2)=3, T(4)=7, T(8)=15, T(16)=31, ...`（都是 2n-1）

---

## 4. T(n) = T(n/2) + 1，T(1) = 1（令 n = 2^k）

**展開**（每下一層問題減半且只呼叫一次，一個 +1）：

```
T(n) = T(n/2) + 1
     = T(n/4) + 1 + 1
     = ...
     = T(1) + k ，其中 k = log2(n)
```

**精確解**：`T(n) = log2(n) + 1`（n = 2^k）
**Big O**：`O(log n)`（主定理 case 2：a=1, b=2, f(n)=1 = Θ(n^0)）

驗證：`T(1)=1, T(2)=2, T(4)=3, T(8)=4, T(16)=5, ...`（等於 log2(n)+1）

---

## 綜合比較表

| # | 遞迴式               | 精確解的數字                         | Big O      | 對應演算法類型        |
|---|----------------------|--------------------------------------|------------|-----------------------|
| 1 | T(n)=T(n-1)+8        | `8n - 7`                            | `O(n)`     | 線性掃描，例如迴圈加常數 |
| 2 | T(n)=2T(n-1)+9       | `5·2^n - 9`                         | `O(2^n)`   | 指數，例如暴力列舉、凍河 (Towers of Hanoi) |
| 3 | T(n)=2T(n/2)+1       | `2n - 1`                            | `O(n)`     | 每層 +1 的合併式遞迴，如樹的高+節點 |
| 4 | T(n)=T(n/2)+1        | `log2(n) + 1`                       | `O(log n)` | 二分搜尋、二元搜尋樹的高度 |

觀察重點：

- **#1、#2 是「每次減 1」**：n 一步一步縮小，複雜度取決於每層加多少 / 呼叫幾次。
- **#3、#4 是「每次除以 2」**：只會有 `log2 n` 層；#4 每層只呼叫一次所以是 `O(log n)`，
  #3 每層呼叫兩次所以變成 `O(n)`。
- **#2 最容易爆炸**：`O(2^n)`，n 只要到 30 以上就慢到跑不完。
